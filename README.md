# نور وهدى — Nur und Huda

نسخة أولية ثابتة لموقع مصلى المستشفى التعليمي.

## الصفحات
- `index.html`: الصفحة الرئيسية وبطاقة المواقيت غير المفعلة
- `sermons.html`: منبر الجمعة
- `together.html`: نصلّي معاً
- `quran.html`: القرآن الكريم
- `library.html`: المكتبة الإسلامية
- `legal.html`: مصادر وتراخيص وصفحات قانونية قيد الإعداد

## تنبيه
المواقيت والجماعات والإشعارات ولوحة الإدارة غير مفعلة. لا تعرض بيانات تجريبية بوصفها بيانات حقيقية.

## التشغيل
افتح `index.html` في المتصفح، أو انشر الملفات الثابتة على GitHub Pages. لا مفاتيح سرية في المشروع.
